Lock Game

Stop the moving highlight on each required digit to crack the locks. Each stage becomes faster and the target window gets smaller.

How to play

A five-digit code is shown in the centre. Stop the moving highlighted section when it covers the next required digit. A miss resets progress on that lock. Complete four stages, each containing five digits.

Space or the Stop button stops the rotor. You can also tap the dial. Use Skip lock if you want to move on.
